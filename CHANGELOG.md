# Changelog

## 1.0.0 (versionCode 1) – 2026-11-09

First release.

- Ball-and-paddle arcade gameplay with gravity and angle-based paddle bounces.
- Difficulty grows with time survived and every 10 hits; speed cap 1.85×; paddle shrinks slightly.
- Strict one-life rule – one miss ends the game.
- Personal best + persistent TOP 3 leaderboard (gold, silver, bronze).
- Game over screen with NEW HIGH SCORE animation, TOP 3 achievement, NEW GAME / MAIN MENU / EXIT GAME.
- Pause with 3-second resume countdown.
- Main menu, How to Play, About (Burhan Nexus logo, clickable email and phone), sound ON/OFF.
- Neon visual style, glow effects, particles, ball trail; responsive for all screen sizes.
- No permissions, fully offline, no ads.
